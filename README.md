# Snap Links Plus

Snap Links Plus is a Browser Addon that lets you lasso links, checkboxes and other elements and do things with them.

**Quick Tutorial:** Once installed, "lasso" links on a page by holding the right mouse button and dragging the cursor over them, then release the button to open in new tabs.

**See our [website](https://cpriest.github.io/SnapLinksPlus/) for news, tutorials, release notes, etc.**

### GNU/Linux
On Firefox-based browsers for GNU/Linux, the long-standing [right click pulls context menu before snap drag](https://github.com/cpriest/SnapLinksPlus/issues/400) issue blocks links from being selected, making Snap Links Plus difficult to use. Given the lack of recent activity on the underlying Firefox bugs ([bug 1443482](https://bugzilla.mozilla.org/show_bug.cgi?id=1443482) and [bug 1448442](https://bugzilla.mozilla.org/show_bug.cgi?id=1448442)), bringing fresh attention to them on Bugzilla can help prioritize a fix.

Meanwhile, [Linkclump for Firefox](https://addons.mozilla.org/en-US/firefox/addon/linkclump-for-firefox/) serves as a solid alternative for end-users. It is activated by holding the Z key, then holding the left mouse button and dragging the cursor over links, then release the button to open in new tabs.
