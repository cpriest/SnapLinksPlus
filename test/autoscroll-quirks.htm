Autoscroll, long page in quirks mode (no DOCTYPE, like the 2016 ldraw.org case)

Here documentElement.clientHeight is the page height and body.clientHeight is the viewport. Standards mode version: autoscroll.html.

  1. Window not maximized: start a right-drag near the top and drag below the window. The page scrolls down, faster the further below. Drag back up above the window: it scrolls up.
  2. Window maximized: drag down into the bottom 20px. The page scrolls, faster closer to the edge. Same at the top 20px when dragging up.
  3. Right-click near the bottom edge with a tiny wiggle: the page does not scroll, and the context menu works.
  4. Start a drag near the bottom and move sideways: no scroll.
  5. Release after scrolling: the label count matches the links that open.
